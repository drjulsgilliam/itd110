Patch's CSS Check

Six short rounds. About 20 minutes. You get an explanation for every answer.

This checks the four things you're meant to walk out of the CSS lesson knowing:

  • Tell inline, internal and external CSS apart, and know when to use each
  • Name every part of a CSS rule and define the key terms
  • Choose the right selector — element, class, ID, combinator or pseudo-class
  • Predict which rule wins (the cascade and specificity) and use the box model

Nothing is saved to a server. When you finish you'll get a summary to paste into Canvas — so don't close the tab until you've copied it.
